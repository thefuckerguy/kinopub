# WooF Installer для macOS

Графическая утилита для безопасной установки WooF.Play на принадлежащие вам iPhone и iPad.

## Что умеет

- находит доверенные устройства, подключённые по USB или Wi‑Fi;
- показывает установленную версию WooF.Play;
- одной кнопкой проверяет обновления, собирает, подписывает, устанавливает или обновляет и запускает WooF.Play;
- обновляет за один запуск все доступные по Wi‑Fi iPhone и iPad, продолжая работу при сбое одного из них;
- проверяет подпись, bundle ID, срок профиля и наличие устройства в выбранном IPA;
- устанавливает и запускает готовый development/ad hoc IPA;
- регистрирует новый телефон через Xcode Automatic Signing, собирает и устанавливает приложение;
- запускает официальный процесс Apple для включения режима разработчика и объясняет подтверждение на устройстве;
- проверяет новые коммиты в `origin/main`, выполняет только безопасный `git pull --ff-only` и ставит свежую сборку;
- проверяет GitHub Releases, скачивает IPA по HTTPS и сверяет SHA‑256, когда GitHub предоставляет digest.

Утилита не обходит ограничения Apple. На Mac должен быть установлен Xcode, в **Xcode → Settings → Accounts** должен быть добавлен ваш Apple ID, а на телефоне — включён режим разработчика. Для нового устройства используется официальный флаг Xcode `-allowProvisioningDeviceRegistration`.

Если на iPhone установлен код‑пароль, Apple может отклонить автоматическую команду `devmodectl`. В этом случае не отключайте защиту: включите режим вручную в **Настройки → Конфиденциальность и безопасность → Режим разработчика**, подтвердите перезагрузку, после запуска нажмите **Включить** и введите код‑пароль.

При первой development‑установке iPhone может потребовать отдельно подтвердить сертификат в **Настройки → Основные → VPN и управление устройством**. Установщик распознаёт эту ситуацию и показывает точную инструкцию.

Для обновлений по воздуху каждое устройство нужно один раз сопрячь с Mac и доверить ему. Затем Mac и iPhone/iPad должны быть в одной локальной сети, а режим разработчика должен быть включён. Кнопка **«Обновить все по Wi‑Fi»** сама обновит список, получит актуальный `main` и последовательно установит свежую сборку на все доступные устройства. Офлайн‑устройства будут обновлены при следующем запуске, когда станут доступны по Wi‑Fi.

## Сборка

```sh
./scripts/build-app.sh
```

Готовое приложение появится в `build/WooF Installer.app`. Его можно перенести в `/Applications`.

Подписанные IPA не публикуются автоматически: development/ad hoc profile может раскрывать UDID разрешённых устройств. Основной безопасный сценарий обновления — получить исходники из Git и подписать новую сборку локально через Xcode.
